# llms.txt — отчёт о генерации: maxmobiles.ru

**Дата:** 2026-08-07
**Режим:** Generation (файл на сайте отсутствовал — `https://maxmobiles.ru/llms.txt` вернул 404)

## Как собран список страниц

Источник — реальный sitemap сайта (`https://maxmobiles.ru/maps/sitemap.xml`, индекс из robots.txt), а не выдуманные URL:
- `maps/categories1.xml` / `categories2.xml` — товарные категории
- `maps/pages1.xml` — статические страницы (гарантия, оплата, о нас и т.д.)
- `maps/products1.xml` — карточки товаров (не включались в llms.txt — их слишком много, 10-30 позиций хватает на уровень категорий)

Каждый из 27 URL, попавших в файл, проверен запросом с `User-Agent: GPTBot/1.2` и подтверждён кодом **200** непосредственно перед включением (лог проверки ниже).

## Отобрано / всего

- **27 страниц** из ~250+ обнаруженных в sitemap — в пределах рекомендованного диапазона 10-30.
- Разделы: `Docs` (10 — справочные/сервисные страницы), `Products` (11 — товарные категории верхнего уровня), `Services` (6 — сервисный центр и ремонт по типам устройств).

## Принцип приоритизации

- Всегда включены: главная, «О нас», контакты, гарантия, доставка, Trade-In, FAQ, отзывы, возврат, политика конфиденциальности.
- Из каталога — только категории **верхнего уровня** (iPhone, Mac, iPad, Apple Watch, AirPods, аксессуары, гаджеты, Android-смартфоны, мультимедиа, красота и здоровье, Б/У Apple). Модельные подкатегории (`iphone-16-pro-max` и т.п., их 150+) и карточки товаров не включены — это ниже порога значимости для 10-30-строчного файла верхнего уровня.
- Сервисный центр — hub-страница + 5 разделов ремонта по типу устройства (iPhone, MacBook, iPad, Apple Watch, iMac). Модельные страницы ремонта (`remont-iphone-16-pro-max` и т.п.) не включены по той же причине.

## Пограничные случаи (можно добавить позже)

- `/podarochnye-sertifikaty/`, `/kredit/`, `/apple-trade-in/trade-in-iphone/` — второстепенные страницы, не включены в первую версию.
- Блог (`/maps/blog1.xml`) не проверялся отдельно — на момент аудита `blog_categories1.xml` из индекса возвращал 404-контент (см. `GEO-CRAWLER-ACCESS.md`, раздел «Технические находки»), поэтому раздел `## Blog` в файл не добавлен, чтобы не включать непроверенные ссылки.

## Рекомендуемая частота обновления

Ежеквартально, либо при добавлении новой крупной товарной категории или значимом изменении контактных данных/условий доставки.

## Как задеплоить

Черновик лежит в `GEO-AUDIT/llms.txt`. Для публикации нужно разместить файл по адресу `https://maxmobiles.ru/llms.txt` (корень домена) — через панель хостинга/CMS. Автоматическая выкладка на сервер не выполнялась, как и было оговорено.
